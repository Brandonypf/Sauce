# Hackathon Arbitrum

Proyecto desarrollado para la Hackathon de Arbitrum.

## Tecnologías

- Solidity
- Foundry
- Hardhat
- OpenZeppelin
- Arbitrum Sepolia
- Alchemy
- MetaMask

## Comandos útiles

### Compilar

```bash
forge build
```

### Ejecutar pruebas

```bash
forge test
```

### Levantar Anvil

```bash
anvil
```

### Desplegar

```bash
forge script script/Counter.s.sol:CounterScript --broadcast
```
