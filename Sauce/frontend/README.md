# base44

Plantilla base Vite + React + Tailwind CSS (shadcn/ui listo).

## Estructura

- `src/` — código de la app (api, components, hooks, lib, pages, utils)
- `entities/` — modelos/entidades del dominio
- `functions/` — funciones backend (cloud functions)
- `config.json` — configuración de la app

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm run preview` — previsualizar build
- `npm run lint` — eslint
